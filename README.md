# ORDENA

Aplicación móvil para restaurantes que permite gestionar mesas, items, pedidos y reportes con almacenamiento local en SQLite.

## Módulos
- Home: indicadores y pedidos activos
- Mesas: configuración de mesas
- Productos: catálogo de productos
- Parámetros: configuración general
- Reporte: listado de pedidos y exportación de base de datos

## Ejecutar
- Instalar dependencias: npm install
- Iniciar: npm run start
- Android: npm run android
- iOS: npm run ios
